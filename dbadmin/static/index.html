Kun for superadmin

Log ind i portalen med superadmin-kontoen og opdatér denne side.

Databaser

Brugerdata og observationer ligger i hver sin gruppe af Postgres-noder. API'et er load balancer: skrivning til gruppens primary, læsning (valgfrit) fordelt på replikaer.

Tilføj node

Tokenet er databasens adgangskode. Opret noden her, kopiér den genererede docker compose til serveren, start den – den første primary i hver gruppe skal findes, før API'et kan bruge opsætningen.
